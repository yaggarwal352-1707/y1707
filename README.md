# 🇮🇳 Incredible India – Festivals & Cultural Heritage Website

A responsive and interactive website celebrating India's rich cultural heritage, vibrant festivals, traditional arts, and regional diversity. Built using HTML, CSS, and JavaScript.

## 🌟 Features

- 🪔 **Indian Festivals:** Explore Diwali, Holi, Durga Puja, Pongal, and Onam.
- 🎭 **Indian Traditions:** Discover classical dance, music, cuisine, and traditional clothing.
- 🏛️ **Cultural Heritage:** Learn about monuments, ancient architecture, folk art, and handicrafts.
- 🗺️ **Regional Diversity:** Explore the unique cultures of North, South, East, and West India.
- 🔍 **Interactive Search:** Search for festivals, traditions, monuments, and regions.
- 📱 **Responsive Design:** Compatible with desktops, tablets, and mobile devices.
- ✨ **Interactive Pop-ups:** Get information about popular Indian festivals.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layouts, animations, and responsive design
- **JavaScript** – Search functionality, navigation, and interactive elements
